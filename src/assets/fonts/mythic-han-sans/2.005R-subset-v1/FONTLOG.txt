Modifications
-------------

1. Instantiated the upstream wght variable axis independently at 400, 500,
   and 600 for SC and TC.
2. Subset SC to the approved 65-code-point Hans set and TC to the approved
   36-code-point Hant set. The fallback-only probes U+6D4B and U+6E2C were
   intentionally excluded.
3. Removed variable tables and the obsolete STAT naming references.
4. Renamed all primary family, full, unique, and PostScript records so the
   Modified Version uses Mythic Han Sans SC / TC and does not use the Reserved
   Font Name. Original copyright, trademark, author, vendor, and OFL records
   remain embedded.
5. Encoded deterministic WOFF2 output through fontTools subset.save_font with
   timestamp recalculation and the optional HarfBuzz repacker disabled. The
   generator rejects Python, fontTools, or Brotli versions outside the exact
   production record before reading either source font.

No glyph outlines were redrawn. Two independent output directories were built
from the same locked inputs; every corresponding file had the same byte length
and SHA-256 digest.
